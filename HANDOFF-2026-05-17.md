## Repo state

GitHub: `ankittandon/rosey` (Ankit's fork — what gets deployed) + `aloktiagi/rosey` (upstream/canonical).

**Two branches**:

- **`main`** — clean self-host product. Top-level Python files (`agent.py`, `app.py`, `scheduler.py`, `telegram_bot.py`, `whatsapp_handler.py`, etc.), `baileys/` sidecar, `website/` marketing site, `scripts/`. This is what self-hosters clone and what gets pushed as `registry.fly.io/rosey-hh-tmpl` for the hosted-fleet base image.
- **`hosted`** — SaaS router only. Contains `router/` package (Flask + SQLite + provisioning), `DESIGN-telegram-funnel.md`, `HANDOFF.md` (the previous one). Disjoint file tree from `main` — share zero source files. Linked at runtime via the `HOUSEHOLD_TOML` env-var contract.

Both branches are pushed to `origin/main` and `origin/hosted`.

The split is intentional: `main` is the open-source-clean self-host story; `hosted` is the SaaS router that ankit runs on top. Future PRs to `aloktiagi/rosey` go from `main` (or feature branches off `main`). The `hosted` branch is Ankit's alone.

## What landed today (in commit order, on `main`)

1. **Pre-launch polish** (committed before today's session started) — image support in baileys, agent confirmation echoes, website restructure
2. **Router v2 onboarding FSM** + design doc + handoff (these now live on `hosted` branch after the split)
3. **Branch split** — extracted `router/` to `hosted` branch, removed from `main`
4. **`scripts/start.sh`** — hypercorn binds `[::]:8080` (IPv6 dual-stack). Required for the router to reach household VMs over Fly 6PN. IPv4-mapped fallback keeps local health checks working.
5. **`household.py`** — `_member_id` accepts `telegram_id`, `telegram_username`, and legacy `phone` shapes. Added `household_name` (title) and `upfront_context` (about section) optional TOML fields.
6. **WhatsApp voice via Whisper** — `baileys/index.js` downloads `audioMessage`, base64-forwards `audio_b64`/`audio_mime`. `whatsapp_handler.py` transcribes via `transcribe.transcribe_audio`. Group gate: only quoted replies to the bot trigger transcription (mirrors Telegram `_voice_addressed_in_group`).
7. **WhatsApp quote-reply gate bypass** — `is_reply_to_bot` flag set when `contextInfo.participant` matches bot JID. Group messages bypass the classifier when set.
8. **`@rosey` strip in group text** — regex pass after the gate decision strips trailing/inline `@rosey` mentions so the agent doesn't try to look them up as household members.
9. **Website**: about page rewrite, "We host it for you" badge (was "Free 30-day trial"), mobile responsive CSS (`<= 720px` and `<= 420px` breakpoints), "Who lives in your house" question copy, "Roommates / co-living" dropdown option, byline reframe ("built by Ankit Tandon based on the open source project"), Rosey logo PNG + email header PNG for Mailchimp.
10. **Static SVG QR** — replaced JS-rendered qrcode.js approach (was failing on rosey.house) with a pre-generated SVG asset at `website/qr-rosey-household-bot.svg`. Removed the jsdelivr CDN dependency.
